# ラディ

材料・半導体・宇宙など、朝のサイエンスニュースを約90秒で読む、個人の放送局です。

▶ 公開先：https://mimizumimizuku.github.io/radi/

## この局について

- [myradio](https://github.com/monoradio102/myradio) のテンプレートで作った局です。お手本の局は「ものラジオ」です。
- プレーヤーは `index.html`、台本は `episodes/` の JSON、局の情報は `station.json` にあります。
- 試し放送の回では、音声にものラジオの公開音声を参照しています。
